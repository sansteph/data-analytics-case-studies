# Google Data Analytics Capstone Portfolio

A collection of data analytics case studies completed as part of the Google Data Analytics Professional Certificate.

## Projects

1. **[Cyclistic Bike-Share Case Study](./CyclisticBikeShare_CS1/)**
   * **Tools:** BigQuery SQL, Tableau, R
   * **Focus:** Consumer segmentation, membership conversion, and ride duration patterns.

2. **[Bellabeat Consumer Wellness Tracker Analysis](./Bellabeat_CS2/)**
   * **Tools:** Python (pandas, numpy, seaborn, matplotlib), Jupyter Notebook
   * **Focus:** Smart device physical activity, sedentary behavior, and sleep cycle optimization.
